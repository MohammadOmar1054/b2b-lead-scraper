# Requirements
This system works on scraping the database of [Prospeo](https://app.prospeo.io/search/people).
To scrape the database from the system , An API key is created from [prospeo-API_KEY](https://app.prospeo.io/api). 

## Packages & Frameworks required:
```bash 
pip install python-dotenv
```
to access the API_KEY from the .env file. 

```bash
pip install pandas
```
for cleansing the extracted data

```bash
pip install openpyxl 
```
for exporting the data to excel sheet. 


```bash
pip install requests
```
downloads and installs the requests library from the Python Package Index (PyPI) into your Python environment. Once installed, it allows you to easily interact with the internet by sending HTTP requests through your Python code
